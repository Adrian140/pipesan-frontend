# PipeSan — audit și reparații, 29 octombrie 2026

## Starea livrării

Reparațiile interfeței sunt în copia locală; nu au fost publicate pe www.pipesan.eu. Cele șase migrări de reparație au fost aplicate în Supabase. Funcția send-order-emails a fost publicată, dar trimiterea nu este configurată. Integrarea Stripe nouă este pregătită local și dezactivată. La cererea utilizatorului, verificarea contului Stripe și activarea Resend sunt amânate.

Acesta este un audit funcțional și de securitate al fluxurilor inspectate, nu o certificare că nu mai există alte defecte.

## Probleme și reparații

| Problemă observată | Reparație / stare |
| --- | --- |
| Catalog, autentificare și operații simulate; API inexistent | Fluxurile active folosesc Supabase; adaptoarele vechi nu mai generează succese fictive |
| Login administrativ fictiv și protecție insuficientă | Auth real, rol din profilul bazei, rute protejate și politici restrictive |
| Profiluri cu acces prea larg / posibilă schimbare de rol | Acces propriu/admin; câmpurile de identitate, rol și MFA protejate prin trigger |
| Înregistrarea ignora metadatele | Trigger pentru nume, telefon, companie și țară; sincronizare email confirmat |
| Facturi și fișiere cu acces insuficient delimitat | Scriere admin; descărcare doar pe baza unei facturi asociate proprietarului |
| 18 fișiere de factură fără asociere exactă în metadata | Păstrate; acces client restricționat. Necesită asociere verificabilă, nu atribuiri ghicite |
| Total comandă calculat înainte de inserarea liniei | Recalculare după modificarea liniilor |
| Checkout simula plata | Simularea eliminată; plata rămâne oprită până la validarea integrării reale |
| Prețuri/TVA/transport calculate arbitrar în browser | Pregătit calcul server din catalog, TVA Stripe Tax, transport 9,99 EUR / gratuit de la 100 EUR fără TVA |
| Coș pierdut la reîncărcare / cantități invalide | Persistență StrictMode, validare, plafon de stoc și maximum 99 pe linie |
| Pagina succes putea sugera o plată neconfirmată | Citește comanda proprietarului; doar status paid confirmă plata și consumă cantitățile cumpărate |
| Emailuri marcate trimise fără expediere | Coadă reală, identificator provider, retry și idempotency; fără reexpediere automată a istoricului |
| Lipsă notificare internă suplimentară / Reply-To | contact@prep-center.eu inclus ca destinatar și Reply-To |
| Notificări de transport inserabile anonim | Inserare restricționată la fluxuri server/admin |
| Recenzii cu autoaprobare și expunere email/note interne | Câmpuri de moderare protejate; rânduri complete accesibile doar proprietarului/admin în limita politicilor existente; recenziile legacy publicate doar de admin |
| Pagini produs hardcodate, filtre defecte, URL-uri nesigure | Date reale după UUID, filtrare/sortare, stoc, fallback imagini, URL http(s), linkuri Amazon normalizate |
| Formulare admin care nu salvau corect | Mapare câmpuri DB, creare vizibilă, categorie, activ/ciornă, urmărirea stocului; conținutul public se reîncarcă după salvare |
| Cont client incomplet / erori ascunse | Adrese, facturare, facturi și comenzi reale; mesaje de eroare; schimbare/resetare parolă reale |
| MFA, VIES, contact/download simulate | Eliminare succese false; explicație/fallback de contact unde serviciul nu este configurat |
| Dependențe vulnerabile / build și importuri | Actualizare dependențe, lockfile, lint, teste și build |

## Verificări efectuate

- `npm run lint`: PASS.
- `npm test`: 37 teste PASS în 6 fișiere.
- `npm run build`: PASS; avertisment rămas pentru pachetul principal ~613 kB necomprimat.
- Audit npm: 0 vulnerabilități raportate la verificare.
- Browser: 40 produse, filtre pe categorie, detaliu real, adăugare în coș și persistență, redirect admin fără autentificare; checkout fără confirmare falsă.
- SQL: teste în tranzacții anulate pentru separarea profilurilor, protecția rolurilor/facturilor, coada email, rezervare stoc idempotentă, expirare/restituire o singură dată, respingere sumă greșită și webhook repetat.
- SQL suplimentar: inserările anonime de recenzii legacy/notificări sunt respinse; recenziile private nu sunt vizibile anonim.
- Verificare finală DB: 40 produse, 12 categorii, 5 utilizatori, 6 comenzi, 0 rezervări checkout, 24 politici `pipesan_*`. Cele 9 mesaje queued sunt istorice (2025), fără event_key; workerul nou le exclude de la expediere.
- Worker email: cheia publică nu poate declanșa expedierea (401).
- Nu au fost efectuate plăți reale sau trimise emailuri de test către clienți.

## Ce împiedică relansarea completă

1. Verificarea contului asociat cheii Stripe existente, Stripe Tax și webhook; test cap-coadă în sandbox. Nu a fost modificat contul Stripe deschis în browser.
2. Publicarea funcțiilor create-checkout/checkout-webhook și activarea checkout numai după verificare. Rezervările fără sesiune Stripe confirmată au nevoie de reconciliere; rambursările/disputele nu sunt încă sincronizate automat.
3. Resend: verificarea domeniului, cheie dedicată cu acces minim, sender și procesare periodică securizată a cozii; test de livrare către adresele interne autorizate.
4. Asocierea celor 18 PDF-uri de factură la proprietari din dovezi verificabile.
5. Publicarea și testarea interfeței reparate pe hostingul real. Versiunea publică nu este actualizată prin simpla modificare a acestei copii locale.
6. Configurarea endpointului formularului de contact, dacă se dorește trimiterea directă; momentan există fallback email. MFA și verificarea VIES nu sunt implementate.

Fluxul pregătit folosește cont confirmat, EUR și aceeași adresă de facturare/livrare în opt țări (FR, DE, IT, ES, NL, BE, PL, RO). Traducerile și textele comerciale/certificările existente necesită revizie editorială separată. Nu au fost validate toate afirmațiile comerciale din catalog.
